# 유형별 예시

원문은 실제 LLM 출력에서 자주 보이는 패턴이다. 제품 맥락은 일부러 다양하게 섞었다.

## 말투 혼용

| 원문 | 수정안 | 사유 |
|---|---|---|
| 카메라를 다른 작업이 잡고 있다. 재검사는 촬영이 끝난 뒤 가능하다 | 촬영이 끝나면 다시 검사할 수 있어요 | 문어체 선언 → 해요체 |
| 어두운 칸으로 보드를 옮겨라 | 어두운 칸으로 보드를 옮기세요 | 명령형 해라체 → 해요체 |
| 파일을 저장했습니다 (상태 배지 자리) | 저장 완료 | 상태 자리는 명사형 |
| 판정은 hold-out이 한다 | 판정 기준: hold-out 오차 | 선언문 → 라벨 + 값 |

## 설계 메모 잔존

| 원문 | 수정안 | 사유 |
|---|---|---|
| 이 화면은 별도 프로젝트에서 설계한다. 여기는 자리와 관문만 둔다 | (삭제) 또는 "측정 기능은 준비 중이에요" | 개발자 메모 |
| 임시 텍스트, 나중에 교체 | (삭제) | 개발자 메모 |

## 역할 불일치: 헤딩

| 원문 | 수정안 | 사유 |
|---|---|---|
| 장비 점검: 허브 [재검사] · 측정 관문 · 게이트가 공유 | 장비 점검 | 헤딩에 아키텍처 설명 |
| 회차 간 산포, 재현성이 진짜 오차 막대다 | 회차별 결과 비교 | 주장문 |
| 사용자가 자주 묻는 질문들을 모아서 정리한 페이지 | 자주 묻는 질문 | 설명문 |
| 지금 바로 시작하는 나만의 워크스페이스 | 워크스페이스 만들기 | 슬로건 |

## 역할 불일치: 버튼

| 원문 | 수정안 | 사유 |
|---|---|---|
| 이 회차로 결과를 산출합니다 | 결과 산출 | 문장 |
| 계속 진행하시겠습니까? (버튼) | 계속 | 질문은 다이얼로그 본문 자리 |
| 클릭하여 업로드 | 업로드 | "클릭하여"는 군더더기 |
| 다음으로 넘어가기 | 다음 | 길이 |

## 역할 불일치: 라벨

| 원문 | 수정안 | 사유 |
|---|---|---|
| 이메일 주소를 입력하세요 (라벨) | 이메일 | 지시문은 플레이스홀더 자리 |
| 확정 뷰 (40–60) | 확정 뷰 / 보조: 목표 40~60 | 기준치 괄호 병기 |
| \|평균 법선\| (≤0.70) | 평균 법선 / 보조: 0.70 이하 | 수식 기호 |

## 잠금·비활성 사유

| 원문 | 수정안 | 사유 |
|---|---|---|
| 잠김: 캘리브레이션 먼저. 관문: 리그 READY 신선 + calibration.json 신선 | 보정을 먼저 끝내 주세요 | 내부 조건식 노출 |
| 권한이 없어 이 기능을 사용할 수 없습니다 (ROLE_ADMIN 필요) | 관리자만 쓸 수 있어요 | 코드값 노출 |

## 빈 상태

| 원문 | 수정안 | 사유 |
|---|---|---|
| 데이터가 없습니다 | 아직 기록이 없어요. 첫 측정을 시작해 보세요 | 다음 행동 없음 |
| 검색 결과가 존재하지 않습니다 | 검색 결과가 없어요. 다른 단어로 검색해 보세요 | 번역투 + 다음 행동 없음 |

## 에러

| 원문 | 수정안 | 사유 |
|---|---|---|
| 죄송합니다. 오류가 발생했습니다. 다시 시도해 주세요 | 저장하지 못했어요. 다시 시도해 주세요 | 사과 + 무엇이 안 됐는지 없음 |
| 잘못된 입력입니다 | 이메일 형식을 확인해 주세요 | 책임 전가 + 해결법 없음 |
| Network Error (code 503) | 서버에 연결하지 못했어요. 잠시 후 다시 시도해 주세요 | 코드 노출 |

|---|---|---|

| 설정을 통해 알림을 관리할 수 있습니다 | 설정에서 알림을 끌 수 있어요 | ~를 통해 |
| 당신의 프로젝트 | 내 프로젝트 | 당신 |

## 용어 흔들림

## 유지해야 하는 것

규칙에 걸리는 것처럼 보여도 손대지 않는 경우.

| 원문 | 판단 |
|---|---|
| 저장 | 유지. 이미 역할에 맞음 |
| RMS 0.22px · hold-out 0.8cm (엔지니어 화면 메타데이터) | 유지. 독자가 엔지니어이고 메타데이터 줄 |
| 삭제하면 되돌릴 수 없어요 | 유지. 확인 다이얼로그에 필요한 정보 |
| 축하해요! 첫 측정을 마쳤어요 | 유지. 축하 문구의 느낌표는 허용 |
