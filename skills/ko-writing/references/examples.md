# 유형별 예시

원문은 실제 LLM 출력에서 자주 보이는 패턴이다. 맥락은 일부러 다양하게 섞었다.

## 번역투

| 원문 | 수정안 | 사유 |
|---|---|---|
| 이 변경은 빌드 시간의 단축을 가능하게 합니다 | 빌드가 40초에서 12초로 줄었습니다 | 무생물 주어 + "가능하게 한다" |
| 설정 파일을 통해 동작을 제어할 수 있습니다 | `config.yaml`에서 동작을 바꿉니다 | "~를 통해" |
| 해당 이슈에 대한 대응이 필요합니다 | 이 이슈를 먼저 처리해야 합니다 | "~에 대한" |
| 테스트가 정상적으로 수행되어졌습니다 | 테스트 191개가 통과했습니다 | 피동 남용 + 수치 없음 |
| 구조적인 개선을 통한 유지보수성의 향상 | 파일을 기능별로 나눠 고치기 쉬워졌습니다 | "~적", "~화", 명사 나열 |
| 앞서 언급된 문제를 해결하기 위해 도입된 새로운 방식 | 새 방식은 위의 두 문제를 해결합니다 | 영어 어순 수식어 |

| 원문 | 수정안 | 사유 |
