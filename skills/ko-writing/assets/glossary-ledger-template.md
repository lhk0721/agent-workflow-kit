# 용어표: [원고 이름]

원고 옆에 `<원고 이름>.terms.md`로 저장한다. 본문을 쓰기 전에 채운다. 형식과 규칙은
ko-writing skill의 `references/ledgers.md`다. check.py는 `--glossary` 옵션으로 아래 표를 읽는다.

- 한 표기는 한 뜻이다. 재료에서 한 표기가 두 뜻으로 쓰였으면 행을 둘로 나누고 표기를 따로 준다
- 행 순서는 본문에서 정의하는 순서다
- 정의 위치는 절 번호("1-4")나 헤딩 글자다. 분야 상식이라 정의하지 않을 용어는 `-`

| 표기 | 뜻 | 쓰지 않을 말 | 정의 위치 |
|---|---|---|---|
| | | | |

## 나눈 표기

재료에서 한 표기가 두 뜻으로 쓰인 곳과 나눈 결과.
