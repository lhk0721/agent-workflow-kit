# 사실 대장: [원고 이름]

원고 옆에 `<원고 이름>.facts.md`로 저장한다. 본문을 쓰기 전에 재료를 처음부터 끝까지
훑어 채운다. 형식과 규칙은 ko-writing skill의 `references/ledgers.md`다. check.py는
`--facts` 옵션으로 아래 표를 읽는다.

- 대상은 본문에 쓸 이름 그대로이고 용어표 표기와 같다
- 값은 본문에 쓸 숫자 그대로다. 표본이 없으면 `-`
- 같은 대상, 같은 지표에 값이 둘이면 아래 "어긋남"에 옮기고 쓰기 전에 푼다

| 대상 | 지표 | 값 | 표본 | 조건 | 재료 위치 |
|---|---|---|---|---|---|
| | | | | | |

## 어긋남

재료끼리 맞지 않는 곳. 푼 결과를 적고, 풀지 못한 것은 사용자에게 물은 날짜와 답을 적는다.

| 대상 | 재료 A (위치, 값) | 재료 B (위치, 값) | 결정 |
|---|---|---|---|
| | | | |
